# Contribution logs

**Each of us copies [TEMPLATE.md](TEMPLATE.md) to `<firstname>.md` and adds a line whenever we work on Part B.** Five minutes a week. The log feeds the contributions form (shares of effort must add to 100%) and is the evidence if peer marks are ever questioned.

Good evidence links: a GitHub issue or commit, a notebook section, a figure, a video segment, a page of research notes. Record AI-tool use in the same line, for example "used an AI assistant to debug the loader; checked by rerunning the split".
